6. Kubernetes Orchestration & Scaling (Docker Desktop / kind)
------------------------------------------------------------
    # Apply manifests
    kubectl apply -f Practical_13_Kubernetes/deployment.yaml
    kubectl apply -f Practical_13_Kubernetes/service.yaml

    # Scale to 3 replicas
    kubectl scale deployment irrigation-need-prediction --replicas=3

    # Check rollout status
    kubectl rollout status deployment/irrigation-need-prediction

    # Port forward to localhost:8080
    kubectl port-forward service/irrigation-need-prediction-service 8080:80

    # Rollback release
    kubectl rollout undo deployment/irrigation-need-prediction

7. Automated Continuous Delivery (GitHub Actions + Self-Hosted Runner)
---------------------------------------------------------------------
    - Workflow file: .github/workflows/kubernetes-cicd.yml
    - CI Stage (ubuntu-latest): Builds Docker image, validates health check, runs unittests, pushes to GHCR.
    - CD Stage (self-hosted runner): Runs kubectl set image, monitors rollout status, verifies in-cluster health.
    - Defensive Rollback: Automatically executes kubectl rollout undo if rollout or health verification fails.

8. Data Drift Surveillance & Retraining
---------------------------------------
    # 1. Prepare reference baseline
    python drift/prepare_reference.py

    # 2. Simulate stable telemetry (no drift)
    python drift/simulate_current_data.py --mode stable
    python drift/detect_drift.py
    python drift/retrain_candidate.py   # Retraining skipped (preserves production model)

    # 3. Simulate environmental drought drift
    python drift/simulate_current_data.py --mode drift
    python drift/detect_drift.py         # Flags overall drift

    # 4. Retrain candidate model & evaluate quality gate
    python drift/retrain_candidate.py    # Trains candidate (85.45% accuracy)
    python drift/approve_candidate.py    # Evaluates threshold (>= 0.85) and promotes model
    python -m unittest test_app.py test_irrigation_ml.py
